# BigEarthNet-MM Preprocessed Subset for LoRA Fine-Tuning (P1 -> P2 Handoff)

This dataset was generated by the **P1 Geospatial Preprocessing Pipeline** for **P2 (VLM Adaptation & VQA)** fine-tuning.

## Dataset Overview

- **Total Samples**: 1,500 paired multimodal patches
- **Train Set**: 801 patches (`train.jsonl`)
- **Validation Set**: 699 patches (`val.jsonl`)
- **Combined**: 1,500 patches (`dataset.jsonl`)
- **Split Strategy**: Strictly adheres to official BigEarthNet train/validation splits (zero spatial data leakage).
- **Quality Filtering**: Cloud-contaminated and heavy cloud-shadow patches were removed.
- **Image Resolution**: 224 × 224 pixels (standard input size for PaliGemma, Qwen2-VL, CLIP).
- **Format**: 8-bit normalized PNG with min-max percentile contrast stretching.

## Directory Structure

```
data/bigearthnet_subset/
├── README.md               # This handoff documentation
├── dataset_info.json       # Dataset metadata and specifications
├── train.jsonl             # Training records (801 items)
├── val.jsonl               # Validation records (699 items)
├── dataset.jsonl           # Complete dataset (1,500 items)
├── images/                 # Normalized Sentinel-2 Optical RGB images (224x224 PNG)
│   └── S2A_MSIL2A_*.png
└── sar/                    # Normalized Sentinel-1 SAR Dual-Pol images (224x224 PNG)
    └── S2A_MSIL2A_*_sar.png
```

## JSONL Schema Example

Each line in `train.jsonl` and `val.jsonl` is a JSON object with this exact shape:

```json
{
  "id": "S2A_MSIL2A_20170803T094031_N9999_R036_T34TCR_26_19",
  "image_path": "images/S2A_MSIL2A_20170803T094031_N9999_R036_T34TCR_26_19.png",
  "sar_path": "sar/S2A_MSIL2A_20170803T094031_N9999_R036_T34TCR_26_19_sar.png",
  "text": "High-resolution remote sensing patch capturing land cover consisting of Broad-leaved forest, Complex cultivation patterns, Inland waters in Serbia.",
  "labels": [
    "Broad-leaved forest",
    "Complex cultivation patterns",
    "Inland waters"
  ],
  "country": "Serbia",
  "split": "validation"
}
```

## Quick Start for P2 (Loading in Python / Hugging Face)

### 1. Load with Hugging Face `datasets`
```python
from datasets import load_dataset
import os

# Load dataset
dataset = load_dataset(
    "json",
    data_files={
        "train": "data/bigearthnet_subset/train.jsonl",
        "validation": "data/bigearthnet_subset/val.jsonl",
    }
)

# Example item
sample = dataset["train"][0]
print("Patch ID:", sample["id"])
print("Prompt Text:", sample["text"])
print("Labels:", sample["labels"])
```

### 2. Loading with PyTorch / PIL
```python
import json
from pathlib import Path
from PIL import Image

data_dir = Path("data/bigearthnet_subset")

with open(data_dir / "train.jsonl") as f:
    for line in f:
        item = json.loads(line)
        img = Image.open(data_dir / item["image_path"])
        sar = Image.open(data_dir / item["sar_path"]) if item["sar_path"] else None
        caption = item["text"]
        break
```
